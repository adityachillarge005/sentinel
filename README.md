
# Sentinel – Intelligent Fraud Detection Platform

An end-to-end Machine Learning platform for detecting
potentially fraudulent financial transactions.

## Project Overview

Sentinel uses Machine Learning to analyze financial
transactions, estimate fraud probabilities, classify
transaction risk, and provide prediction explanations.

## Technology Stack

- Python
- NumPy and Pandas
- Scikit-learn
- Django REST Framework
- PostgreSQL
- HTML, CSS, JavaScript and Bootstrap

## Project Status

Currently in development.

## Project Structure

- data/       - Dataset storage
- notebooks/  - ML experiments and analysis
- src/        - Independent ML pipeline
- backend/    - Django REST API
- frontend/   - Dashboard
- tests/      - Automated tests
- docs/       - Project documentation

## Disclaimer

This project is for educational and research purposes.
It is not connected to real banking systems.
